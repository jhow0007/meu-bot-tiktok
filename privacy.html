Política de Privacidade

Última atualização: 14/11/2026

Dados coletados

Ao autorizar o app, recebemos do TikTok o identificador (open_id), nome de exibição e avatar do usuário, e um token de acesso para publicar vídeos.

Uso dos dados

Os dados são usados exclusivamente para publicar os vídeos que o próprio usuário escolhe. Não vendemos nem compartilhamos dados com terceiros.

Armazenamento

Os tokens ficam salvos apenas no computador do usuário. Nenhum dado é enviado a servidores próprios.

Exclusão

O usuário pode revogar o acesso a qualquer momento nas configurações do TikTok e apagar o arquivo de token local. Pedidos de exclusão podem ser feitos pelo GitHub deste projeto.

LGPD

Tratamos dados conforme a Lei 13.709/2018.
